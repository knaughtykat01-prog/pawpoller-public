# Security policy

## Reporting a vulnerability

Please email **security@pawpoller.com** instead of opening a public issue, so the problem can be fixed
before it's widely known. Include:

- what you found and what an attacker could do with it,
- steps to reproduce it,
- the PawPoller version (Settings → About & updates) and whether it's the desktop app or a server install.

You'll get a reply, and credit in the release notes if you'd like it.

## Supported versions

Fixes go into the latest release. Every install updates itself from
[the releases page](https://github.com/knaughtykat01-prog/pawpoller-public/releases), so the newest
version is the one to test against.

## Other contacts

- Privacy and your data: **privacy@pawpoller.com**
- Everything else: **support@pawpoller.com**

This policy is also at [pawpoller.com/security](https://pawpoller.com/security/#report), and machine-readable at
[/.well-known/security.txt](https://pawpoller.com/.well-known/security.txt).
